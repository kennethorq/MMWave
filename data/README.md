
## **Data**

The preprocessed datasets can be downloaded from Google Drive:

- **Amazon datasets:** [Baby / Sports / Clothing](https://drive.google.com/drive/folders/13cBy1EA_saTUuXxVllKgtfci2A09jyaG?usp=sharing)

These datasets include pre-extracted **textual** and **visual** features obtained using Sentence-Transformers and CNN-based image encoders, respectively.


For experiments on the **TikTok** dataset, we use the version provided by [MMSSL](https://github.com/HKUDS/MMSSL).



> **Note:** Please place the downloaded datasets in this directory before model training.
